🇨🇦 Ryan쌤 · 사이트 편집

웹사이트의 문구, 색상 강조, 시간표, 영상, PDF, 달력을 관리합니다. 이 페이지의 주소는 공개되어 있지만 게시 권한은 GitHub가 확인합니다.

🔐 GitHub 연결

GitHub에서 만든 Fine-grained personal access token을 사용합니다. Repository access: Only select repositories → ryan-english-classes, Permissions: Contents → Read and write. 토큰은 이 탭의 메모리에만 보관하며 서버나 저장소에 저장하지 않습니다. 개인 기기에서만 사용하세요.

토큰을 입력한 뒤 사이트를 불러오세요.

✏️ 웹사이트 문구 전체 편집

현재 사이트의 제목, 설명, 강조된 문구 등을 순서대로 표시합니다. 색깔이 적용된 문구는 별도 항목으로 나와요. 글을 수정하면 기존 색상은 유지됩니다.

🎨 색상과 디자인

칠판 배경의 분필 색상을 조절할 수 있어요. 밝은 배경에서는 같은 색 계열의 진한 색상을 자동으로 적용해 글씨가 잘 보이도록 합니다.

🎥 수업 설명 영상

유튜브 일반 링크 또는 공유 링크를 붙여 넣으면 공개 사이트에서 바로 재생됩니다.

🗓️ 월간 달력 이미지

이미지는 GitHub 저장소에 업로드됩니다. 새 파일을 선택하지 않으면 기존 달력이 유지됩니다.

📚 수업 샘플 PDF

업로드한 PDF는 공개 사이트에서 열거나 다운로드할 수 있습니다. 업로드한 파일은 공개됩니다.

👀 미리보기

문구, 색상, 시간표와 기존 영상·달력·PDF가 미리보기에 반영됩니다. 새로 선택한 업로드 파일은 게시 후 연결됩니다.

🚀 변경 사항 게시

문구와 월간 정보를 GitHub에 게시합니다. 이미지와 PDF를 선택했다면 함께 업로드합니다. 반영까지 몇 분 걸릴 수 있어요.

아직 게시하지 않았습니다.
